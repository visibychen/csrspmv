# v3: direct CSR register transpose

This independent branch starts at original master 9352c86, without v1/v2 history. Default CLI backend remains original.

~~~
make CFLAGS='-O3 -march=native -g -Wall -iquote src -fopenmp'
OMP_NUM_THREADS=24 ./csrspmv input.mtx --kernel=v3 --repeat=9 -v
make check CFLAGS='-O3 -march=native -g -Wall -iquote src -fopenmp'
~~~

For eight consecutive rows of length eight, v3 reads their current CSR values/columns, pairs rows0/4 through3/7 in YMM halves, and transposes four positions at a time. Each SIMD lane accumulates one output row in its original order. There is no persistent SELL copy, matrix reorder, horizontal row reduction, padded x read, cached Ax, or replacement of R updates by R*Ax.

Local eligibility is checked during execution. Noneligible blocks and tails use generic CSR. The new translation unit disables FP contraction, retains compiler vectorization for the generic path, and uses target AVX2 helpers guarded by runtime feature detection. Other types use the unchanged original implementation. Portable builds omit march=native; compile with NO_OPENMP=1 and omit fopenmp for serial-only use.

| Option | Behavior |
| --- | --- |
| --kernel=original/v3 | original is the global default |
| --v3-backend=tile8 | selected default after independent finite calibration |
| --v3-backend=auto | tile8 plus short, balanced four-row scalar interleaving |
| --v3-backend=pipeline4 | explicitly interleave four independent rows |
| --v3-backend=csr | matched-FP generic CSR control |
| --v3-balance=work/rows | weighted contiguous rows (default) or equal rows |
| --v3-serial-threshold=N | default32768 events; zero disables size rule |

Both option syntaxes are accepted. Preparation fully checks row pointers and column indices, using at most one validation team. Validation, ISA checks and selection are charged to P. No dynamic auxiliary memory is allocated. Row boundaries use the current team and F(i)=row_ptr[i]+i; this does not split giant rows and is not claimed as a new v3 contribution. Every collective call keeps its completion barrier.

Values/x may change per call. Rebuild after structural/type changes; output y must not overlap x or CSR storage. NaN/Inf, signed zero, empty rows and nonzero initial y retain real arithmetic semantics. Negative/overflowing targets and impossible positive flops on zero matrices are rejected.

The default calibration used eight independent shapes and288 observations. auto did not satisfy the predeclared non8-group improvement/regression rule, so tile8 was retained; formal holdouts do not tune defaults. Full performance acceptance is separate in the materials repository.

The common CSR binary fixture and unified benchmark are experimental infrastructure shared by original/v2/v3, not production v3 features or credited I/O speedups. A production CLI corroboration is retained. ISA semantics reference the official GCC11.4 x86 Function Attributes and Built-in Functions documents; the transpose mapping was independently implemented.
